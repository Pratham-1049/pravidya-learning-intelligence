Product rules

This is a frontend prototype.

Use clearly identified mock data.

Do not create Supabase or another database.

Do not implement a separate authentication system.

Do not add paid AI APIs.

Do not pretend that AI functionality is already connected.

Keep API calls in a separate service layer for future Express backend integration.

Do not build all product modules at once.

Build the application shell and dashboard first. Make it polished, functional and responsive.
